# Quillnote
> A notebook that files itself
Quillnote keeps plain-text notes, links them to each other, and tells you when two notes disagree about the same fact.

## Write
- **capture**: a new note from anywhere
- **templates**: start from a saved shape
- **daily**: one note per day, made for you

## Find
- **search**: every word, every note
- **tags**: filter by what you tagged
- **backlinks**: what points here

## Keep it true
- **drift**: two notes that disagree
- **stale**: notes nobody opened in a year
- **duplicates**: the same note twice

## Share
- **export**: Markdown or PDF
- **publish**: one note as a web page
